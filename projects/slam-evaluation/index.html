Project Summary
Problem

在动态、遮挡或退化工况下，对不同 SLAM 方案的定位误差、稳定性和实时性进行统一评估。

My Role

围绕方案调研、评估框架组织、实验比较逻辑和结果表达方式展开。

Technical Focus

ATE、RPE、实时性、鲁棒性、系统资源消耗、实验口径统一。

Technical Thinking

这类项目的关键不在于简单罗列算法名，而在于你如何定义“公平比较”、如何设计退化工况、 如何选择评价指标，以及最终怎样把结果转化为工程决策依据。这样的表达会让项目页更有技术判断力。
