About Me

当前的能力结构更接近“算法研发 + 工程落地”的组合型技术画像。

能力覆盖 Transformer 与时序建模、Ray 分布式训练与实验组织、机器人感知与系统集成、 AI Agent / MCP 工具链设计。目标方向聚焦深度学习算法、模型训练基础设施、具身智能相关研发与机器人系统工程。

Definition

当前能力结构主要沿三条主线展开。其一是模型训练与算法研发，重点围绕 Transformer、自注意力机制、 多模态时序建模、异常检测、实验设计与结果分析，能够完成从数据处理、训练流程搭建到实验验证与结果整理的完整研发过程。 其二是机器人感知与系统实践，围绕 ROS2、传感器接入、点云链路调试、激光惯性里程计、地图构建与环境建模展开， 关注真实平台中的工程可用性与系统联调。其三是 AI 辅助研发工具链，重点在于将 AI Agent、多智能体协作与 MCP 架构用于研发提效， 形成可复用的任务拆解、上下文组织、代码辅助、调试协同与文档整理流程。

Detailed Capability View

模型训练与实验组织

模型训练相关能力以 PyTorch 为核心，覆盖训练脚本组织、实验配置管理、结果对比分析与模型验证。 关注训练效率、实验可复现性与模型研发闭环，也具备使用 Ray 进行并行实验、训练调度与参数搜索的经验， 适合面向训练平台、实验编排与模型优化相关场景。

机器人感知与系统实践

机器人相关能力聚焦于 ROS2 环境下的系统实践，覆盖四足机器人平台、Livox 激光雷达、点云处理链路、 SLAM 方案调研与实验尝试，以及 grid map、ESDF、环境建模等方向。重点不只在算法概念本身， 也在于真实系统中的接入、调试、验证与快速迭代。

AI Agent / MCP 工具链

AI Agent 与 MCP 相关能力强调工程落地，而不仅是工具使用。重点包括工具接入、上下文编排、任务拆解、 代码生成辅助、调试协同、研发流程优化与多工具协作链路设计，目标是将前沿 AI 能力真正接入研发过程， 提升开发效率与问题推进速度。

How I Work

Engineering-Oriented

整体工作方式偏工程导向与闭环导向。重视问题定义、模块职责、实验路径、结果证据与系统可维护性， 强调从想法验证到实际落地的完整推进能力。

Closed-Loop Iteration

面对新方向时，优先建立最小可运行闭环，再逐步补齐评估、文档、实验组织与系统结构。

Target Directions

当前更关注的技术方向包括深度学习算法、分布式训练与实验基础设施、机器人感知与系统集成、 具身智能相关研发，以及面向研发提效的 AI Agent 工具链设计。
